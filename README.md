# 🛡️ SmartVAPT — Tri-Vector Attack Surface Analyzer & AI Reporting Engine

SmartVAPT is an automated Vulnerability Assessment & Penetration Testing (VAPT) tool with a Streamlit dashboard. It combines **three scan vectors** — network, web application, and DNS/email security — into a single workflow and produces a professional, evidence-backed **PDF report**, optionally enriched with **AI-generated narratives** via Google Gemini.

Built as part of the **ICT Academy of Kerala – Cyber Security Analyst (VAPT)** program.

## 🔍 What It Does

| Vector | Tooling | Checks |
|---|---|---|
| **Network Scan** | Nmap + `vulners` NSE script | Port discovery, service/version detection, CVE correlation |
| **Web App Audit** | Python requests, OpenSSL, gobuster | HTTP security headers, TLS analysis, technology fingerprinting, directory & sensitive-path enumeration, robots.txt/sitemap review |
| **DNS / Email Security** | `dig` / host lookups | SPF record, DMARC record, MX and related DNS hygiene |
| **Findings Engine** | `findings.py` | Normalizes all findings, deduplicates, assigns severity (Critical / High / Medium / Low / Info) |
| **Evidence Store** | `evidence.py` | Saves raw tool output per scan (`evidence/<scan_id>/`) so every finding is reproducible |
| **AI Reporting** | Google Gemini (`ai_engine.py`) | Executive summary, per-finding impact analysis, prioritized remediation roadmap (optional — requires API key) |
| **PDF Report** | fpdf2 | Branded assessment report: `SmartVAPT_<scan_id>.pdf` |

### 🤖 AI-Powered Reports (Google Gemini)

The PDF report can be automatically enriched with an **executive summary, per-finding impact analysis, and a prioritized remediation roadmap** generated by Google Gemini.

1. Get a free API key: <https://aistudio.google.com/apikey>
2. Set it in your shell (add to `~/.bashrc` to make it permanent):
   ```bash
   export GEMINI_API_KEY="your-api-key-here"   # your key — never commit this to git
   ```
3. Launch the dashboard and tick **"Enable AI analysis"** before starting a scan:
   ```bash
   streamlit run main.py
   ```
4. Download the PDF — AI narratives are embedded per finding and in the executive summary.

> Without a key, the tool still works fully; the AI section is skipped gracefully.
> ⚠️ Treat your API key like a password. If it ever appears in chat/logs/repo history, regenerate it immediately at aistudio.google.com.

## 📦 Requirements

- **Kali Linux / Debian / Ubuntu** (recommended; works on any Linux/macOS)
- Python **3.10+**
- System tools:
```bash
sudo apt update
sudo apt install -y nmap gobuster dnsutils libpango-1.0-0 \
    libpangocairo-1.0-0 libgdk-pixbuf-2.0-0 fonts-dejavu-extra
```
> `gobuster` is optional — the dirb vector degrades gracefully if it's missing.
> PDF generation uses pure-Python fpdf2; only the DejaVu fonts are needed for proper rendering.

## 🚀 Installation

### Option A — One-command installer
```bash
git clone https://github.com/lichenvarghese-cyber/SmartVAPT.git
cd SmartVAPT
chmod +x install.sh
./install.sh
```
`install.sh` creates a virtual environment, installs Python dependencies, and sets up Nmap capabilities.

### Option B — Manual
```bash
git clone https://github.com/lichenvarghese-cyber/SmartVAPT.git
cd SmartVAPT
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## ▶️ How to Run

```bash
source .venv/bin/activate      # if using the venv
streamlit run main.py
```
Then open **http://localhost:8501** in your browser.

### Using the dashboard
1. Enter a **Target** (IP, domain, or URL).
2. Toggle the scan vectors you want:
   - ☑ Network Scan (Nmap + vulners)
   - ☑ Web App Audit (headers + dirs)
   - ☑ DNS / Email Security (SPF + DMARC)
3. Choose the **port selection** (default: **Nmap Top 1000 ports** — nmap's ranked list of the 1,000 most commonly used ports out of all 65,535, via `--top-ports 1000`). Other options: Top 100 (quick), Ports 1-1000 (full low-range sweep with `-p 1-1000`), or a custom range/list such as `80,443,8000-9000`.
4. Click **Run SmartVAPT Scan**.
5. Review live progress, the findings table, and download the **PDF report**.

### Enable AI narratives (optional)
```bash
export GEMINI_API_KEY="your-api-key-here"   # get one at https://aistudio.google.com/apikey
streamlit run main.py
```
Without the key the tool still works fully — the AI section simply reports that the key is not configured.

## ✨ Merits / Why SmartVAPT

- **Tri-vector coverage in one pass** — network, web, and email/DNS posture assessed together instead of stitching 3–4 separate tools.
- **Evidence-first design** — every finding is backed by raw tool output saved under `evidence/<scan_id>/`, making reports auditable and reproducible (a core VAPT deliverable requirement).
- **Professional PDF reporting** — branded, severity-ranked reports ready to hand to clients, not just console dumps.
- **AI-assisted analysis** — Gemini turns raw findings into executive summaries and prioritized remediation guidance, cutting report-writing time dramatically.
- **Beginner-friendly, pro-useful** — one-click Streamlit UI ideal for students learning VAPT methodology, while the modular Python backend can be scripted or extended.
- **Graceful degradation** — missing optional tools (gobuster, API keys) never crash the scan; affected vectors are clearly reported.
- **Free & open source** — built entirely on open tooling (Nmap, gobuster, dig) plus an optional free-tier Gemini key.

## 🐛 Troubleshooting

| Symptom | Fix |
|---|---|
| PDF renders with missing glyphs | Ensure DejaVu fonts are installed (`fonts-dejavu-core`) |
| PDF text/font errors | `sudo apt install fonts-dejavu-extra` |
| Nmap results empty on ports <1024 | Run as root, or give Nmap raw-socket caps: `sudo setcap cap_net_raw,cap_net_admin,cap_net_bind_service+eip $(which nmap)` |
| "GEMINI_API_KEY not configured" | `export GEMINI_API_KEY=...` before launching Streamlit |
| gobuster step skipped | `sudo apt install gobuster` (optional) |
